# SEU 讲座查询

参考 [only9464/seuszjz](https://github.com/only9464/seuszjz)，查询东南大学 ehall
学生素质讲座预约系统。适用于本项目的 NcatBot 5.x + NapCat QQ 适配器。

## 用法与输出预览

私聊机器人或在机器人所在群发送 `/讲座`，无需 @、无需管理员权限。
机器人发送合并转发聊天记录：首条为数量及数据时间，之后每场讲座占一条消息。

```text
用户：/讲座
机器人：[聊天记录 · SEU 讲座助手]
  东南大学 · 当前素质讲座，共 2 场，数据时间……（北京时间）
  1. 人工智能讲座
     讲座状态：未开始
     预约状态：可预约
     时间、地点、主讲人、系列、主办单位……
     名额：已预约 90/100，剩余 10
     预约时间……
  2. ……
```

当前讲座指未取消且结束时间尚未到达的讲座；按开始时间升序排列。
缺少结束时间的记录保留，不擅自推测结束时间。
预约状态分为可预约、未开放、已满、预约已截止、状态未知；讲座进行状态单独显示。
“预约已截止”对应参考项目按预约截止时间推导的 ended，不等于讲座已经结束。
空列表也以聊天记录返回“暂无尚未结束的讲座”。超过 50 条消息会分成多份聊天记录。
网络、认证和发送失败以普通文字提示，查询失败不会伪装成空列表。

## 配置与启动

将环境变量设置在**启动机器人的同一个进程环境**中：

```powershell
$env:SEU_USERNAME = "你的学号或一卡通号"
$env:SEU_PASSWORD = "你的统一身份认证密码"
$env:SEU_NETWORK = "auto"
.venv/Scripts/python.exe main.py
```

`SEU_NETWORK` 可选 `auto`（默认，探测是否跳转校外网关）、`campus`（校园网直连）或
`offcampus`（校外 aTrust 网关）。自动识别错误时显式设置所在网络。
请通过服务器环境管理配置真实密码，不在群聊发送；插件不提供聊天登录命令。
未配置账号时插件仍可加载，收到 `/讲座` 后提示管理员配置。
更换环境变量后需重启机器人，或在已更新环境的进程内重载插件。

依赖已写入 manifest；当前工作区已安装。手动部署时可执行：

```powershell
.venv/Scripts/python.exe -m pip install -r plugins/seu_lectures/requirements.txt
```

查询使用同一个服务账号，所有用户看到公共讲座信息。不会展示该账号的学号、
个人预约状态、预约码、打卡或违约记录。插件只查询列表，不预约、不取消预约。
Cookie 仅保存在内存中；查询结果缓存 60 秒，并发查询串行复用缓存；会话失效后
重新登录一次。单次网络请求最多 15 秒，整次查询最多 60 秒（不含等待前一个查询）。
遇到短信等二次验证会提示管理员在学校网页处理；不保证网页验证后一定可以协议登录。
