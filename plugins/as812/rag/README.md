# 聊天记忆与 RAG

所有聊天入口通过 `MessageHandler.build_chat_history` 统一处理记忆。只检查本次已加载的有限历史和当前消息，不增加历史消息条数，也不扫描全部聊天日志。

## 自动记忆

- 从用户原话中筛选稳定偏好、姓名、居住地、主武器、职业、生日等明确陈述，例如「我喜欢太刀」「我住在南京」。也支持「812，记住：我的生日是 5 月 1 日」。
- 疑问、引用、临时状态、玩笑、密码等凭据、明显的提示词指令和机器人自己的回复不自动入库。筛选采用保守规则，不能覆盖所有自然语言表达。
- 记忆保留说话人的昵称、QQ、会话和原始陈述时间。群聊之间、群聊与私聊之间隔离；问「我喜欢什么」时只匹配当前说话人的记忆。
- 重复加载同一历史不会增加记忆或刷新寿命。新陈述可以刷新记忆；姓名、生日、主武器等单值信息按时间纠正，旧历史不会覆盖较新的事实。
- 自动记忆使用独立的 ChromaDB `chat_memory` collection，通过固定哈希特征在本地索引，不请求额外的 LLM 或 Embedding API。检索依赖词语重合，不保证匹配所有同义改写。

## 弱化与遗忘

普通记忆初始强度为 0.7，明确要求记住的信息为 0.95。强度从最后一次用户陈述开始按指数衰减，默认每 30 天减半；检索命中不会续期。

低于 0.12 或超过 180 天的记忆不再参与回复。在后续记忆处理时清理过期记录，全库清理最多每小时一次；每个会话最多保留 200 条，超限优先淘汰弱记忆。没有会话活动时无需后台任务，下一次检索仍会按实际时间计算强度。

原有手动导入的知识继续保存在 `default` collection，不自动衰减。现有 `/记忆` 命令仍表示添加手动知识；自然聊天中的「记住：……」进入可衰减的聊天记忆。统计、列表、删除和清空操作同时覆盖两个 collection。

## 精简上下文

知识与记忆合计默认最多注入 3 条、600 字符，标题和提示模板也计入预算。装不下的条目跳过，不截断事实。没有相关结果时不添加 RAG 提示；已经出现在本次可见短期对话中的同一事实也不重复注入。

`cat_prompt.txt` 的头像外观事实已迁入 `background_knowledge.txt`，加载插件时幂等写入本地知识索引，按需检索、不自动衰减。身份、称呼、性格、说话方式和互动边界仍留在提示词中。清空知识库后，这份随代码发布的背景知识会在下次加载插件时重新导入。

## 配置

以下配置可加入 `plugins/as812/config/config.yaml`，省略时使用这些默认值；修改后重载插件：

```yaml
rag_memory_enabled: true
rag_memory_half_life_days: 30
rag_memory_max_age_days: 180
rag_memory_max_per_scope: 200
rag_context_top_k: 3
rag_max_context_chars: 600
```

`rag_enabled: false` 同时关闭记忆采集与上下文注入。`rag_memory_enabled: false` 仅关闭自动记忆的采集与召回，保留手动知识及背景知识。原有手动知识仍使用 `rag_trigger_mode` / `rag_trigger_keywords` 和既有嵌入配置；聊天记忆和背景知识的本地检索不依赖关键词触发。
